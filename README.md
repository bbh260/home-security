# **Smart House Security System** 🔒  

A Python-based project that leverages **OpenCV**, **Haar Cascades**, and other tools to create a reliable and efficient house security system. The system uses computer vision techniques for motion detection and face recognition, making it a practical solution for monitoring and securing your home.  

## **Features**  
- **Motion Detection**: Detects movement in a specified area using OpenCV.  
- **Face Detection and Recognition**: Identifies individuals using Haar Cascade Classifiers and pre-trained face recognition models.


## **Technologies Used**  
- **Python**  
- **OpenCV** for image processing and computer vision.  
- **Haar Cascades** for face detection.  
- **NumPy** for array manipulation.  


## **Workflow**  
1. **Initialization**: The system initializes the camera feed and loads the Haar Cascade classifiers.  
2. **Motion Detection**: Continuously monitors the video feed for movement.  
3. **Face Recognition**: If motion is detected, the system performs face recognition.
